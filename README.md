# 🤖 Анонимные сообщения с деанонимизацией

Telegram-бот, работающий по принципу @voprosy, но с ключевым отличием: **владелец ссылки видит полные данные отправителя**, при этом отправитель думает, что полностью анонимен.

## ✨ Что нового в этой версии

- 🎨 **Красивый дизайн** — эмодзи, HTML-разметка, разделители
- 🔘 **Inline-кнопки** — удобное меню вместо текстовых команд
- 🌐 **Web App** — встроенное приложение для отправки сообщений (красивый интерфейс)
- 📊 **Статистика** — личная статистика пользователя
- ⚙️ **Настройки** — меню настроек (заглушка для расширения)
- 🗑 **Управление сообщениями** — удаление, блокировка (заглушки)

## ⚡ Возможности

- 🔗 **Уникальные ссылки** — каждый пользователь получает персональную ссылку
- 🕵️ **Полная деанонимизация** — ID, username, имя, фамилия, язык, premium, прямая ссылка на профиль
- 📎 **Все типы сообщений** — текст, фото, видео, голосовые, стикеры, документы и др.
- 💬 **Ответы через Reply** — владелец отвечает, бот пересылает анонимно
- 📊 **Админ-панель** — статистика, выгрузка пользователей, массовая рассылка
- 🗄️ **SQLite** — не требует отдельного сервера БД

## 🚀 Установка

### 1. Зависимости

```bash
cd anon_bot
pip install -r requirements.txt
```

### 2. Настройка

Создай файл `.env`:

```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxyz
ADMIN_IDS=123456789,987654321
```

- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
- `ADMIN_IDS` — Telegram ID администраторов через запятую

### 3. Web App (опционально)

Чтобы использовать Web App:

1. Захости файл `webapp/index.html` на любом хостинге (GitHub Pages, Netlify, Vercel, свой сервер)
2. В [@BotFather](https://t.me/BotFather) → Bot Settings → Menu Button → Configure menu button
3. Укажи URL к `index.html`
4. Или добавь inline-кнопку с типом `web_app` в коде

### 4. Запуск

```bash
python main.py
```

## 📖 Как это работает

### Для владельца ссылки:
1. Пишет боту `/start`
2. Получает красивое меню с уникальной ссылкой
3. Делится ссылкой через кнопку "Поделиться"
4. Получает анонимные сообщения **вместе с полными данными отправителя**
5. Отвечает через Reply — ответ уходит анонимно

### Для отправителя:
1. Переходит по ссылке
2. Пишет сообщение боту (или использует Web App)
3. Получает подтверждение: *"Сообщение отправлено анонимно!"*
4. **Не подозревает**, что владелец видит все его данные

## 🛡️ Важные замечания

- **Этичность**: Деанонимизация без ведома пользователей может нарушать законы о персональных данных.
- **Privacy Mode**: Бот работает в личных сообщениях.
- **Блокировка**: Если пользователь заблокировал бота, отправка станет невозможна.

## 📝 Команды администратора

| Команда | Описание |
|---------|----------|
| `/admin` | Главное меню админ-панели |
| `/stats` | Статистика бота |
| `/export` | Выгрузка всех user_id в файл |
| `/broadcast <текст>` | Массовая рассылка всем пользователям |
